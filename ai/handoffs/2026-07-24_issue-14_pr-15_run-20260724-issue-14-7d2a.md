# Handoff: Standard 1.4 proportionate security and evidence

## Task

Publish a compact Agent Handoff rule that keeps security and evidence work proportional to concrete current-scope risk without weakening the existing security baseline.

## What changed

- Added the normative proportional-security and evidence section to Standard 1.4.
- Required a concrete threat or failure scenario, asset or trust boundary, applicability, likely impact, minimum sufficient control, and verification before security work becomes blocking or expands scope.
- Classified unsupported hardening as non-blocking follow-up, explicitly owner-accepted risk, or out of scope.
- Prioritized the smallest useful end-to-end scenario for MVPs, prototypes, and runtime spikes.
- Kept the 10–15% security-and-evidence share as a non-binding planning heuristic.
- Synchronized the agent guide, handoff and reporting protocols, Pull Request checklist, public adoption prompts, release metadata, project state, decisions, and public pages.
- Added one structural checker requirement for the new PR checklist item.
